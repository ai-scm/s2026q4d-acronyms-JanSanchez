# s2026q4d-acronyms-JanSanchez

## Sobre el repositorio

Este repositorio reúne explicaciones introductorias sobre cuatro acrónimos relacionados con el diseño de software, la inteligencia artificial y la ciberseguridad. Su propósito es presentar sus conceptos principales y ofrecer una referencia rápida para entender qué significa cada uno y en qué contexto se utiliza.

## Temas

- **GRASP (General Responsibility Assignment Software Patterns):** principios y patrones que ayudan a asignar responsabilidades entre clases y objetos al diseñar software.
- **LLM (Large Language Model):** modelo de lenguaje de gran tamaño, entrenado con grandes cantidades de datos para procesar y generar texto.
- **SOC (Security Operations Center):** centro de operaciones de seguridad que coordina la monitorización, detección y respuesta ante amenazas de ciberseguridad.
- **XSS (Cross-Site Scripting):** tipo de vulnerabilidad web en la que se inyectan scripts que pueden ejecutarse en el navegador de quienes visitan un sitio.
